Politique de confidentialité

Mise à jour : 9 novembre 2026

Ce site de présentation

Ce site présente Pingbuyer. L’application est accessible uniquement sur invitation. Aucun compte ne peut être créé librement depuis cette page.

Compteur de vues

Un badge Hits.sh comptabilise les chargements de la page, et non les visiteurs uniques. Son affichage établit une connexion à Hits.sh. Selon sa politique, le compteur n’utilise pas de cookies et ne collecte pas de données personnelles.

Consulter la politique de Hits.sh

Langue et hébergement

Votre choix de langue est mémorisé localement dans le navigateur et partagé entre le site et l’application. Vous pouvez l’effacer dans les paramètres du navigateur. Aucun traceur publicitaire ni Google Analytics n’est intégré. Le site est hébergé par GitHub Pages ; l’hébergeur peut traiter des données techniques de connexion pour fournir et sécuriser le service.

Consulter la politique de GitHub

Langue automatique

Sans choix de langue enregistré, le navigateur contacte IPWhois pour estimer le pays de connexion à partir de l’adresse IP. Ce service reçoit l’adresse IP ; Pingbuyer ne l’enregistre pas. Seuls le pays et le résultat de détection sont temporairement conservés dans la session du navigateur. En cas d’échec, la langue du navigateur est utilisée. Un VPN peut modifier le pays détecté. Vous pouvez choisir une autre langue à tout moment.
